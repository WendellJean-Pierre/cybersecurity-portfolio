
# Security Control Assessment

**Prepared by:** Wendell Jean-Pierre  
**Organization:** Clearview Community Health (Fictional)  
**Project Type:** Simulated GRC Case Study  
**Status:** In Progress

## 1. Assessment Objective

Evaluate the security controls of Clearview Community Health, identify potential weaknesses, and recommend corrective actions to reduce cybersecurity risks and protect sensitive patient information.

This assessment uses fictional scenarios and illustrative assumptions. No real patient or employer information is included.

## 2. Security Control Assessment

| ID | Security Control | Simulated Current State | Assessment | Recommended Action |
|---|---|---|---|---|
| C-01 | Multifactor Authentication (MFA) | MFA is not consistently enforced | Gap Identified | Require MFA for all applicable accounts |
| C-02 | Access Control | User permissions are not regularly reviewed | Needs Improvement | Implement role-based access and quarterly reviews |
| C-03 | Data Backup | Backups exist, but restoration testing is inconsistent | Needs Improvement | Establish backup restoration testing |
| C-04 | Patch Management | Critical patches are sometimes delayed | Gap Identified | Establish patch deadlines based on risk |
| C-05 | Vendor Risk Management | Vendor security reviews are incomplete | Gap Identified | Conduct documented vendor risk assessments |

**Note:** Current-state descriptions are fictional assumptions for this exercise, not verified audit findings.

## 3. Assessment Methodology

1. Identify critical systems and information assets.
2. Define the expected security controls.
3. Review simulated evidence and control conditions.
4. Document gaps and potential risks.
5. Recommend corrective actions.
6. Assign proposed control owners.
7. Establish remediation priorities.
8. Reassess controls after corrective actions.

## 4. Preliminary Remediation Priorities

| Priority | Control | Proposed Owner | Recommended Action | Verification Evidence |
|---|---|---|---|---|
| Critical | MFA | IT Manager | Enforce MFA | MFA configuration and test results |
| High | Access Control | Privacy Officer | Review user access | Access review records |
| High | Data Backup | IT Manager | Test backup restoration | Restoration test report |
| Critical | Patch Management | IT Manager | Remediate critical vulnerabilities | Patch and scan records |
| High | Vendor Risk | Compliance Officer | Review vendor security | Completed vendor assessment |

Priorities are provisional and will be reviewed against the risk register.

## 5. Validation and Follow-Up

The next phase will document simulated supporting evidence, evaluate whether each control is operating effectively, and track corrective actions.

Control status will be updated as the case study progresses.

## 6. Assessment Conclusion

The preliminary assessment identifies five potential control weaknesses requiring further evaluation.

These findings are based on a fictional healthcare scenario. The next phase will examine supporting evidence, establish remediation actions, and document reassessment results.
